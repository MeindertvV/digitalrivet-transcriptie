# three or more columns of running text: read as columns that run on
LAYOUT OF THIS BOOK: running text in three or more columns.
- Treat it as you would two columns: each column whole, top to bottom,
  from left to right, and the text runs on from one column into the next
  as one text. A sentence broken at a column end just goes on.
- Columns numbered instead of pages: all numbers in <page_number>,
  "305 / 306 / 307".
- If the columns are not running text but a table (cells side by side
  that belong together across a row), follow the table standard instead:
  one <l> per row with " | " between the cells.
