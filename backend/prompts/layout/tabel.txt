# tables: rows and cells (also concordances, synopses, number tables)
LAYOUT OF THIS BOOK: tables.
- Every printed row is one <l>, cells separated by " | ", in the order
  of the columns from left to right; an empty cell is an empty place
  between two " | ". The header row of the table is its first <l>.
- A table that runs over two columns of the page: the left half whole,
  then the right half.
- Tables of numbers only (astronomy, chronology, interest): copy them as
  rows all the same; a number you cannot read is [?] in its cell.
- Running text above, between or below the tables is <p> as usual.
