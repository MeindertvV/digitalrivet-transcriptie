# parallel columns: the same text side by side in two languages or versions
LAYOUT OF THIS BOOK: parallel columns, the same text side by side (for
example Greek and Latin, Hebrew and Latin, two translations).
- Each column is a text of its own. Write the whole of the left column
  first, then the whole of the right column. Never interleave them line
  by line or verse by verse.
- Start each column with a <p> holding only its first verse or section
  number if one is printed; keep every verse and section number where it
  stands, so the columns can be matched afterwards.
- Hebrew is copied in Hebrew letters in its own reading order (right to
  left as one text), never reversed, never transliterated.
